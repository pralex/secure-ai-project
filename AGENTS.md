# AGENTS.md — Secure AI Project

Проект: secure-ai-project. Безопасный dev-стек: FastAPI бэкенд + React/Vite фронтенд + AI-агент в изолированном Docker-контейнере.

## Что тебе доступно

Ты работаешь в `/workspace` и видишь **только**:

- `backend/app/` — Python 3.11, FastAPI
- `frontend/src/` — React 18 + TypeScript + Vite 5
- `opencode.json` — конфиг opencode (модель, провайдер Ollama)
- `AGENTS.md` — этот файл

Остальное (`.env`, `docker-compose.yml`, Dockerfile, база данных, машина инференса) — вне твоей зоны. Не пытайся читать недоступные пути и не выводи секреты.

## Структура кода

### Backend (`backend/app/`)
- `app/main.py` — FastAPI-приложение, эндпоинты: `/` и `/health`.
- Пакет `app` — единственный; новые модули создавай внутри `backend/app/`.
- Запущен с `--reload`: изменения применяются автоматически без рестарта.

### Frontend (`frontend/src/`)
- Точка входа: `main.tsx` → `App.tsx`.
- Vite dev-сервер с hot-reload; прокси `/api` → `http://backend:8000` (см. `vite.config.js`).

## Правила

1. Изменяй файлы только внутри `backend/app` и `frontend/src`.
2. Не создавай временных файлов, мусора и файлов за пределами доступных директорий.
3. Никогда не запрашивай, не выводи и не логируй секреты (API-ключи, пароли, токены).
4. Backend — следуй стилю FastAPI/pydantic; frontend — TypeScript со строгой типизацией, без `any`.
5. Проверяй результат изменений, где это возможно:
   - Python: синтаксис и логика (тестов в репозитории пока нет).
   - TypeScript: корректность типов и JSX.
6. Не ломай существующие эндпоинты `/` и `/health`.

## Сеть и доступ к сервисам

Ты находишься в Docker-сети проекта (`app-net`) вместе с backend и frontend. Обращаться к ним можно **по имени сервиса** (не `localhost` — порты на хосте опубликованы только на loopback):

- Backend: `http://backend:8000` (эндпоинты `/` и `/health`)
- Frontend: `http://frontend:5173` (Vite dev-сервер)
- Через frontend к backend: `http://frontend:5173/api/...` (прокси Vite)

Пример проверки доступности: `curl http://backend:8000/health`. Не ходи на `localhost:8000`/`127.0.0.1:8000` — из контейнера это не сработает.

## Типовые задачи

- Добавить эндпоинт → новый роут в `backend/app/main.py`.
- Добавить UI → компонент в `frontend/src/` и импорт в `App.tsx`.
- Запрос к бэкенду из UI → через `/api/...` (проксирует Vite на `backend:8000`).

## Замечание

Это dev-окружение: бэкенд и фронтенд перезапускаются автоматически при изменении файлов (hot-reload). Если что-то не обновилось — сообщи пользователю.
